## F-01: i18n基盤 + 接続画面日本語化(M0)

### 概要

自前のi18n基盤(`src/app/src/i18n/`)を新設し、未翻訳・孤立キー検出スクリプト(`scripts/i18n-sync.mjs`)を用意する。基盤の動作確認を兼ねて、まず接続画面(TopBar/Connection)を日本語化する。

### 入力

発注者が設定画面で言語を「日本語」に切り替え、gSenderを再起動する。

### 処理

1. 起動時に`workspace.language`をstoreから読み込み、`ja.json`をロード
2. `document.documentElement.lang = 'ja'`を設定
3. 接続画面のコンポーネントで`t()`を用いてラベルを表示

### 出力

接続画面（ポート選択・接続ボタン・ステータス表示等）が日本語で表示される。

### ビジネスルール

- 既存ファイルへの変更は「`import`1行 + `t()`ラップ」に限定する
- `SettingsMenu.ts`等のデータ定義ファイルは編集しない（詳細は`05_技術設計.md`）

### エラーケース

| 条件 | 挙動 |
|:--|:--|
| ja.jsonにキーが無い | 英語表示にフォールバックする |
| `t()`内で動的キー(`` t(`...${x}`) ``)を使っている | `i18n-sync.mjs`がWARNを出し同期対象外とする |

### 完了条件

- ja起動で接続UIが日本語表示になる
- `npm run test:app`が通る
- `npm run build`が成功する
- パッケージ化バイナリを実機CNC（無ければgrblHALシミュレータ）に接続し、接続→ジョグ→切断が日本語UIで完了する
- `npm run i18n:sync`がexit 0（NEW/ORPHANゼロ）

## F-02: 日常操作画面一式 日本語化(M1)

### 概要

workspace/(TopBar, Sidebar, ToolArea, Alerts), JobControl, FileControl, DRO, Jogging, Probe, Macros, Spindle, Coolant, Consoleと、Config画面の描画側5箇所（設定項目約260件を一括対象化）を日本語化する。

### 入力

F-01と同様、`workspace.language=ja`での起動。

### 処理

各機能ディレクトリ単位で、ハードコードされたUI文字列を`t()`でラップし、`ja.json`に翻訳を追加する。

### 出力

日常的なCNC操作（接続・ジョグ・ファイル読込・加工実行・設定変更）が一通り日本語で完結できる。

### ビジネスルール

- `ja.json`翻訳コミットの直前に`npm run i18n:review`で英日対訳表を出力し、通し読みレビューを行う
- レビュー観点: (a)ツールバー/タブ/ボタンは短いか、(b)CNC用語が慣習と合っているか（Home→原点復帰、Probe→プローブ、Jog→ジョグ、Soft limits→ソフトリミット等）、(c)設定名と設定説明で用語が揺れていないか

### エラーケース

| 条件 | 挙動 |
|:--|:--|
| 訳語がCNC操作の誤解を招く可能性がある | レビューで指摘し、同じコミットで修正する |

## F-04: 設定説明文・周辺機能 日本語化(M3・余力)

### 概要

`SettingsDescriptions.ts`（$設定の説明、`EEPROMSection.tsx`で対応）、AccessoryInstaller/ATC, Rotary, SDCard, RemoteMode, サーバー起点メッセージを日本語化する。時間が余った場合のみ着手する。
