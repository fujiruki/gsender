# 01. 概要

## 何を作るか

OSSのCNCコントローラ「gsender」(Sienci-Labs/gsender)をフォークし、UI全体に日本語対応を追加する。react-i18next等は使わず自前の軽量なi18n基盤を新設し、日常操作に必要な画面から段階的に日本語化する。

## 誰のためか

| 項目 | 内容 |
|:--|:--|
| 主なユーザー | 発注者自身とその周辺で、CNCを日本語UIで操作したい人 |
| 利用環境 | PC(Windows/Mac/Linux、Electronデスクトップアプリ) |
| 利用頻度 | CNC加工時に日常的に使用 |

## 解決する課題

| 課題 | 現状 | このシステムでの解決 |
|:--|:--|:--|
| gsenderにUI日本語化の仕組みがない | 本家は1.5のUI大改修時にi18n機構を撤去済み。issue #877でメンテナーが「再整備は将来やるが今は優先度低い」と明言 | フォーク側に自前のi18n基盤を追加し、日本語UIを独自に提供する |
| 英語・CNC初心者には操作用語のハードルが高い | ボタン・設定項目が全て英語 | 日常操作画面(接続・ジョグ・ファイル制御・設定等)を優先的に日本語化する |

## 業務フロー

```
gsender起動 → 言語設定(workspace.language=ja)を読込 → 日本語UIで表示
→ CNC接続 → ジョグ/ファイル読込/加工実行 → 切断
```

## 用語定義

| 用語 | 意味 |
|:--|:--|
| upstream | 本家リポジトリ Sienci-Labs/gsender |
| フォーク | このプロジェクトのリポジトリ fujiruki/gsender |
| 英文キー方式 | `t('Start Job')`のように、翻訳キーとして英文そのものを使う方式。IDキー(`t('job.start')`)は使わない |
| NEW / ORPHAN | `scripts/i18n-sync.mjs`が検出する状態。NEW=コードにあるが未翻訳、ORPHAN=翻訳ファイルにあるがコードから消えた(本家の文言変更の疑い) |
